# 互动实验室

直接用浏览器打开 `index.html`。无需联网、安装或构建；浏览器缩放与键盘操作可用。课程及首课链接指向 Markdown，建议用编辑器阅读。

## 设计约定

- **视觉**：像一张安静的数学实验台，用纸白底色、深色文字和青绿色数据标记，把图形与公式放在中心。
- **内容**：先选择实验，再预测参数变化，操作主图，最后对照数值与边界解释；课程链接作为后续入口。
- **交互**：查询方向改变时同步移动箭头与注意力条；梯度下降按步播放轨迹；观察角度改变时重投影同一曲面。没有自动播放和装饰性循环。

## 数学约定

Attention 实验使用人工指定的二维 `q`、`k`、`v`，用于解释计算，不代表真实词向量。`q = [cos θ, sin θ]`；三个 key 与 value 分别为 `[1,0]`、`[0,1]`、`[-1,0]`；缩放为 `√2`。开启因果掩码后，位置 `i` 只能读取 `j ≤ i`。查询方向是独立控制的实验变量，并非由具体输入 token 的投影计算。

梯度实验使用 `L(w₁,w₂) = ½(w₁² + 4w₂²)`，初始参数 `[2,1.2]`。固定步长梯度下降在 `0 < η < 0.5` 时收敛；`η = 0.5` 时第二坐标等幅振荡；`η > 0.5` 时第二坐标发散。该阈值只适用于这个二次函数。显示范围为 `|w₁|,|w₂| ≤ 3`；越界后暂停并保留实际数值，不截断参数。每次播放最多到累计 80 步，或梯度范数小于 `10⁻⁴` 时停止。

## 验证数值

- Attention 默认 `θ = 0°`、无 mask：得分约 `[0.707107, 0, -0.707107]`，权重约 `[0.575975, 0.283995, 0.140029]`，输出约 `[0.435946, 0.283995]`。
- `θ = 90°`、无 mask：得分约 `[0, 0.707107, 0]`，权重约 `[0.248255, 0.503490, 0.248255]`，输出约 `[0, 0.503490]`。
- 因果 mask、`i = 1`：权重恒为 `[1,0,0]`，输出为 `[1,0]`。
- 梯度默认 `η = 0.15`：第 1 步参数 `[1.7,0.48]`，损失 `1.9058`；起点损失 `4.88`。
