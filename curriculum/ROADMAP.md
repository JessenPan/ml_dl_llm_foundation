# From mathematical intuition to ML, DL, and LLM: integrated route

这条主线的目标是看到一条模型公式时，能回答：每个符号是什么、形状是什么、运算在做什么、为什么这样设计、如何用一个小例子验证。初版按“数学基础较好、希望尽快进入 DL/LLM”设计；根据最新反馈，目前先从[基础桥接](FOUNDATION_BRIDGE.md)学习符号、线代、微积分、概率、统计和优化的基本联系。

The earlier 16-week sketch is expanded into one integrated route of about 26–30 weeks at 4–6 hours per week. It now includes all classic Watermelon Book chapters and Andrew Ng-inspired ML, DL, and LLM concepts. This is a planning estimate; mastery and actual time decide the pace.

## 三层学习深度

1. **直觉层：** 用图、动画、生活类比说清它解决什么问题，并指出类比在哪里失效。
2. **计算层：** 能写出形状、代入数字、手算一个最小例子，再用代码或交互演示核验。
3. **推导层：** 能从定义或前一个结论推出公式，解释假设与边界，处理一个改动后的问题。

每个核心模块至少达到前两层；梯度、反向传播、交叉熵、Attention 和自回归目标要达到第三层。暂不把抽象测度论、一般优化收敛证明或大规模训练工程作为通关条件。

## 每周安排与通关方式

建议拆成 3 次学习：第一次建立直觉和读公式，第二次手算、推导与演示，第三次完成挑战并复盘。每次先回忆旧知识 5–10 分钟，再加入新概念；不需要一次坐满两小时。

一节课只解决一个中心问题，采用“先预测 → 看现象 → 读符号 → 推导 → 小例子 → 改条件 → 解释”的顺序。演示前先猜结果，演示后说明差异，避免只看动画产生熟悉感。

通关需留下四类独立证据：**直觉解释、符号/形状、推导/手算、变式应用**，逐项记录“未评估 / 需提示 / 可独立完成”。默认在能独立解释核心机制、核对关键形状、完成核心计算并解决一道变式题后，进入依赖模块。薄弱项先用 15–30 分钟定向补习后重试；也可以由你决定先继续，并把尚未解决的缺口记录下来。

## 主线课程

### M0 · 起点诊断与路线校准｜不占正式周次

**中心问题：** 现有数学知识，哪些已经能直接用于理解模型？

- [10 道诊断题](DIAGNOSTIC.md)可以在基础桥接过程中按需抽取；已有相关基础时，完整作答约 30–45 分钟。不会的题标记原因，不立即翻答案。
- 按能力而非总分选择起点：张量与线代、求导、概率与信息论、建模、Attention。
- **成果：** 一份起点记录：可跳过、需复习、尚未学过，以及每周实际可投入时间。

### M1 · 张量记号与线性代数的几何意义｜第 1 周

**中心问题：** 一堆数字如何表示数据，矩阵乘法如何改变表示？

- **学会：** 区分标量、向量、矩阵和高阶张量；跟踪 batch、序列、特征轴；把线性映射理解为改变基方向后再组合。
- **数学与符号：** 内积、范数、余弦相似度、基、秩、投影；特征值与 SVD 的几何直觉。主线记号为行向量样本：$X\in\mathbb R^{n\times d}$，$W\in\mathbb R^{d\times h}$，$H=XW+b\in\mathbb R^{n\times h}$。偏置沿样本轴广播。
- **基础范围：** 明确区分 L1 范数 $\|x\|_1$、L2 范数 $\|x\|_2$ 与平方范数 $\|x\|_2^2$；连接特征值与 PCA 的方向直觉。协方差在 M3 介绍后再回看 PCA，完整证明为选修。
- **看得见：** 计划用可拖动向量与 2D 网格变形解释旋转、拉伸和降维；3D 只用于空间投影。当前可在 Attention 演示中观察向量内积与权重变化。
- **验收：** 给定 $X$ 为 $2\times3$、$W$ 为 $3\times2$，手算输出；说明交换两个轴和改变元素值的区别；构造“内积大但余弦不大”的例子。
- **依赖与补习：** 依赖代数运算。若只在记号或广播上卡住，补这一小节；无需重学整本线代。SVD 的完整证明为选修。

### M2 · 矩阵微积分、链式法则与自动微分｜第 2 周

**中心问题：** 最终误差如何告诉每一个参数应该怎么改？

- **学会：** 区分导数、偏导、梯度、方向导数、Jacobian；理解反向模式自动微分在复用局部导数。
- **数学与符号：** $dL=\langle\nabla_W L,dW\rangle_F$；$y=f(g(x))$ 的链式法则；向量–Jacobian 乘积；计算图与梯度累加。只对标量目标使用“梯度”这一称呼。
- **看得见：** 当前梯度下降演示把参数画成地面坐标、损失画成高度；计划增加计算图的逐边反传动画和等高线上的方向导数。
- **验收：** 本例显式采用列参数 $w:d\times1$、目标 $y:n\times1$、数据 $X:n\times d$，推导 $L=\tfrac12\|Xw-y\|^2$ 的 $\nabla_w L=X^\top(Xw-y)$，检查形状；对一个参数做中心差分验证；说明共享参数为什么收到多条路径的梯度之和。
- **依赖与补习：** 依赖 M1。链式法则不熟时，先做一个标量三步函数；Jacobian 张量记号混乱时先用方向导数理解，再恢复完整形式。

### M3 · 概率、最大似然与信息论｜第 3 周

**中心问题：** 为什么“给正确答案更高概率”最后变成最小化交叉熵？

- **学会：** 区分概率与似然；用条件概率表示序列；从最大似然走到负对数似然，再连接熵、交叉熵和 KL 散度。
- **数学与符号：** $p_\theta(y\mid x)$、$\mathbb E[X]$、$\mathrm{Var}(X)$、$H(p)$、$H(p,q)$、$D_{KL}(p\|q)$；$p(x_{1:T})=\prod_{t=1}^{T}p(x_t\mid x_{<t})$。自然对数默认使用 $\ln$。
- **基础范围：** 条件概率与贝叶斯；伯努利 Bernoulli、类别 Categorical、正态 Gaussian 分布；sigmoid/softmax 输出的是分布参数。区分总体期望、样本均值、方差、协方差与相关系数；学习经典中心极限定理的直觉和独立同分布、有限方差等条件，不把它用作任意数据服从高斯的理由。
- **模型连接：** 从独立、零均值、同方差高斯误差的回归模型推到最小二乘；从 Bernoulli/Categorical 条件模型推到分类负对数似然。相关系数需两变量方差非零；零相关不一般推出独立。
- **看得见：** 计划用可拖动分类概率柱解释“自信地猜错为何罚得重”，用编码长度解释 surprisal；不要把 KL 画成满足对称性的距离。
- **验收：** 从独立样本似然推导平均负对数似然；手算三分类 softmax 和交叉熵；解释 $H(p,q)=H(p)+D_{KL}(p\|q)$ 在固定 $p$ 时意味着什么。
- **依赖与补习：** 依赖对数、指数与基本求和。条件概率不熟时补一个两步抽样树；连续分布和测度论暂不展开。

### M4 · 机器学习的建模、目标函数与泛化｜第 4 周

**中心问题：** 训练集上误差很低，为什么仍然可能是坏模型？

- **学会：** 用线性回归和逻辑回归串起数据、参数、预测、目标、优化和评估；分清训练误差与泛化误差。
- **数学与符号：** 经验风险 $\hat R(\theta)=\tfrac1n\sum_i\ell(f_\theta(x_i),y_i)$；L2 正则；sigmoid；偏差与方差的直觉；训练/验证/测试分工。
- **损失与评估：** 明确 MSE、二分类交叉熵、多分类交叉熵各自的求和对象与平均口径；从混淆矩阵学习准确率、精确率、召回率和 F1，再看阈值变化形成的 ROC 与 AUC。区分训练目标和评估指标，结合类别不平衡解释选择。
- **正则化：** 用 $L(\theta)+\lambda R(\theta)$ 统一 L1/Lasso 与平方 L2/Ridge；比较稀疏解与权重收缩的几何直觉，说明它们依赖目标、特征尺度和求解方式，不能把“降方差”当作每个数据集的保证。
- **看得见：** 计划用拟合曲线随模型复杂度变化的动画显示欠拟合、过拟合；用分离的数据点观察分布变化。
- **验收：** 为一个小回归任务写清假设和目标；从数据划分到评估解释完整实验；识别至少两种泄漏；说明测试集不能用于反复调参的原因。
- **依赖与补习：** 依赖 M2、M3。可以跳过熟悉的经典算法横向比较；必须保留实验设计和泛化。

### M5 · 多层感知机与反向传播｜第 5–6 周

**中心问题：** 多层非线性变换怎样学出新的特征？

- **学会：** 从线性层到激活函数到输出分布，完整走过一次前向、损失、反向和参数更新；理解表达能力与优化难度的区别。
- **数学与符号：** $Z^{(l)}=H^{(l-1)}W^{(l)}+b^{(l)}$、$H^{(l)}=\phi(Z^{(l)})$；ReLU/GELU；softmax + 交叉熵对 logits 的梯度 $p-y$（单样本、one-hot 标签、未额外平均）。
- **看得见：** 计划用 2D 决策边界和隐藏空间变形解释非线性；用逐层反传动画显示局部导数相乘与分支累加。
- **验收：** 手算一个“两输入、两隐藏单元、一个输出”的网络；用 NumPy 或等价方式实现一层前后向，再与自动微分结果比较；解释为什么多个纯线性层仍然等价于一个仿射映射。
- **依赖与补习：** 依赖 M1–M4。Python/PyTorch 语法按需补习，不把框架 API 熟练度作为数学通关条件。

### M6 · 优化、初始化、归一化与训练稳定性｜第 7 周

**中心问题：** 公式正确，训练为什么还会震荡、停住或发散？

- **学会：** 关联曲率、学习率、尺度和梯度；理解 SGD、动量、Adam 的机制；知道初始化、LayerNorm 和梯度裁剪分别解决什么问题。
- **数学与符号：** $\theta_{k+1}=\theta_k-\eta\nabla L(\theta_k)$；Hessian 的方向曲率直觉；动量的一阶状态与 Adam 的一、二阶矩估计；归一化均值、方差及 $\epsilon$。
- **看得见：** 当前 3D 二次损失曲面演示比较不同步长；计划增加狭长山谷上的 SGD/动量轨迹、激活与梯度分布图。3D 的高度只是标量损失，真实参数空间通常远高于三维。
- **验收：** 对 $L=\tfrac12(w_1^2+4w_2^2)$ 推出固定步长收敛范围 $0<\eta<\tfrac12$；解释为何该结论不能直接推广为任意神经网络的保证；从一条训练曲线提出可检验的故障假设。
- **依赖与补习：** 依赖 M2、M5。优化器完整收敛证明与自然梯度为选修；不能用“Adam 总是更好”替代分析。

### M7 · 从相似度到 Attention｜第 8–9 周

**中心问题：** 一个 token 如何根据当前需要，从其他 token 取回信息？

- **学会：** 分清 query、key、value 的角色；把 Attention 读成“打分 → 归一化 → 加权取值”；完整跟踪序列轴和特征轴。
- **数学与符号：** $Q=XW_Q$、$K=XW_K$、$V=XW_V$；$P=\operatorname{softmax}_{\text{row}}(QK^\top/\sqrt{d_k}+M)$；$O=PV$。本项目用 $P$ 表示注意力权重，其他教材也可能写作 $A$。掩码 $M$ 在允许位置为 0，禁止位置为 $-\infty$。
- **看得见：** 当前 Attention 演示支持改变 query 角度、因果掩码与当前位置 i，观察权重及输出；计划增加 Q/K/V 形状流和多头对比。
- **验收：** 手算三个 token、二维 key 的一次 Attention；说明 softmax 沿哪个轴；用独立、零均值、单位方差分量的假设解释 $\sqrt{d_k}$ 缩放；解释 Attention 权重为何不能自动当作完整的因果解释。
- **依赖与补习：** 前向依赖 M1、M3，训练推导依赖 M2、M5。若概率归一化不熟先回 M3；不需要先学完整 RNN。

### M8 · Transformer 的结构与信息流｜第 10–11 周

**中心问题：** Attention 如何与其他组件组成可训练的语言模型？

- **学会：** 区分 encoder、decoder、decoder-only；连接多头注意力、输出投影、残差、归一化、FFN、位置编码与因果掩码。
- **数学与符号：** 多头拼接 $\operatorname{Concat}(O_1,\ldots,O_h)W_O$；Pre-LN 残差块；FFN；位置索引；正弦位置编码与 RoPE 的旋转直觉。注意 LayerNorm 的归一化轴与 softmax 的轴不同。
- **看得见：** 计划用可逐层推进的信息流图、二维 RoPE 旋转、因果可见性矩阵；位置依赖用小维度示例，不将二维图当成真实 embedding 地图。
- **验收：** 给定 $B,T,d_{model},h,d_{head}$，写出一个 block 每一步形状；解释去掉位置信息或掩码会造成什么；在选定的 Pre-LN 结构上画清残差路径和归一化位置。
- **依赖与补习：** 依赖 M5–M7。CNN/RNN 可作为比较支线；不要求背诵不同模型所有结构变体。

### M9 · 语言模型的训练目标与数据｜第 12 周

**中心问题：** “预测下一个 token”如何从一行公式变成一批训练样本？

- **学会：** 分清文本、token、ID、embedding、logits 与概率；理解 teacher forcing、标签错位、padding mask、训练/验证分离。
- **数学与符号：** $L(\theta)=-\frac1N\sum_{\text{有效位置 }t}\log p_\theta(x_t\mid x_{<t})$，$N$ 是参与损失的有效位置数；困惑度 $\mathrm{PPL}=e^L$ 在使用自然对数且相同平均口径下成立。
- **看得见：** 计划用逐 token 的输入/目标对齐动画和词表概率条形图；演示错误的标签对齐如何意外泄露答案。
- **验收：** 为一个短序列写出输入、目标与有效损失位置；从 logits 得到总损失；说明不同分词器的 token 级困惑度不适合直接横比；区分预训练与 SFT 的目标和数据组织。
- **依赖与补习：** 依赖 M3、M8。BPE 实现细节可选；必须能解释 token 并不总等于一个词或一个字。

### M10 · 推理、KV Cache 与模型适配｜第 13–14 周

**中心问题：** 训练好的模型怎样生成文本，又怎样以较少参数适配任务？

- **学会：** 比较 greedy、temperature、top-k、top-p；理解 prefill 与逐 token decode；解释 KV cache 的存储/计算取舍；理解 SFT 与 LoRA，对齐方法先建立概念边界。
- **数学与符号：** $p_i=[\operatorname{softmax}(z/\tau)]_i=\exp(z_i/\tau)/\sum_j\exp(z_j/\tau)$，$\tau>0$；softmax 对整个词表的 logits 向量归一化。在本项目行向量约定下，$W\in\mathbb R^{d_{in}\times d_{out}}$，$\Delta W=AB$，$A\in\mathbb R^{d_{in}\times r}$，$B\in\mathbb R^{r\times d_{out}}$。其他资料可能使用 $BA$，必须连同形状一起比较。
- **看得见：** 计划用采样概率与逐步生成动画、KV cache 复用图、低秩矩阵变形。明确标准 causal cache 在缓存既有 K/V 后仍需新 query 与历史 key 计算注意力。
- **验收：** 对同一组 logits 比较温度对分布的影响；说明缓存为什么通常不保存旧 Q；计算给定单层 K/V 的元素数；比较全量微调与指定秩 LoRA 的可训练参数数量。
- **依赖与补习：** 依赖 M1、M8、M9。RLHF、PPO、DPO 的推导和大型部署为选修；主线只需能区分预训练、SFT、偏好优化和推理时采样。

### M11 · 微型 Transformer 与论文阅读｜第 15–16 周

**中心问题：** 能否从一段文本一直解释到参数更新，再从论文公式走回实现？

- **学会：** 以一个小型 decoder-only Transformer 整合整条主线；把论文公式、形状、模块和实验连接起来。
- **成果范围：** 教学规模的字符级或小词表模型，建议从 1–2 个 block、短序列和小隐藏维度开始；先确保能完成一次正确的前后向，再按设备与时间扩展。生成质量不作为理论理解的唯一指标。
- **实验：** 保留独立验证片段，建立简单基线，完成至少一个有假设的消融，例如去掉位置表示、改变头数或调整学习率；记录结果与不能得出的结论。
- **验收：** 不看笔记解释输入到损失的所有形状；手算一个局部例子；定位一处梯度；说明训练和生成时的信息可见性；读懂论文中至少两条核心公式，并写一页“设计动机—公式—实现—实验”的说明。
- **依赖与补习：** 依赖 M1–M10 的核心验收。编程薄弱可先完成带注释的计算图和可运行骨架；理论验收通过后再补实现。完整训练可能超出排课时间，需据实际设备调整规模。

## 如何加速，而不跳过真正的缺口

| 现有能力 | 可压缩内容 | 必须留下的证据 |
| --- | --- | --- |
| 线代熟练，但未用过张量轴 | M1 的基、秩和投影复习 | batch/序列/特征轴题及一个 Attention 形状题 |
| 会求导并熟悉链式法则 | M2 的标量导数 | 矩阵梯度、共享节点梯度累加、一次数值核验 |

通过诊断相关题目后，可以直接尝试该模块验收；通过验收再标记掌握。**只觉得眼熟、看懂答案或能调用框架，不视为掌握。** 如果 M1–M4 都通过，可用 1–2 周进行连接复习后直接进入 M5；主线整体可压缩，但不预先承诺固定毕业日期。

## 按需补习与选修

- **符号补习：** 上下标、求和、集合、函数复合、转置、范数、期望、偏导。遇到符号就查，不按字母表背诵。
- **数学补习：** 指数与对数 → 向量与矩阵 → 链式法则 → 条件概率。只补阻碍当前概念的一段。
- **工具补习：** NumPy 广播、PyTorch 张量与 autograd、数值稳定性、基础绘图。用小数组建立直觉后再调用高层 API。
- **结构选修：** CNN 的局部性与参数共享；RNN/LSTM 与序列状态；图神经网络；稀疏或线性 Attention。
- **理论选修：** SVD/PCA 完整推导、贝叶斯估计、凸优化、泛化界、自然梯度、信息瓶颈。根据问题选择，不把它们当作无限前置条件。
- **LLM 选修：** RoPE 深入、GQA/MQA、MoE、量化、FlashAttention 原理、RLHF/DPO、扩散模型对比。先能解释基线，再研究变体。
