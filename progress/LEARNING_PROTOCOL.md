# 怎么开始、反馈、结束与继续学习

你可以把这个项目当成一位会保留教学记录、逐渐了解你的老师。只要在这个项目里交流，用自然语言即可，无需记准确口令。

## Learning language

Lessons, exercises, feedback, and session summaries use simple English. Standard technical terms stay unchanged and receive a simple explanation when first introduced. You can ask questions or give feedback in Chinese or English. Difficulty with English is recorded separately from difficulty with the mathematics. You can request a Chinese explanation when needed.

## 你说什么，我怎么做

| 你可以这样说 | 助手的行为 |
| --- | --- |
| 开始学习 | 读上次记录，给一个本次小目标，从接续点开始；目前的起点是基础桥接 B0 |

## 一次学习怎么进行

1. **接上次：** 简短回顾已记录的内容；有相关到期复习时，选 1–2 个提取问题。首次学习直接从一个具体例子开始。
2. **确定一个小目标：** 比如“分清输入、参数和预测值”。未给时长时，也先围绕一个小目标推进，不一次讲完整章。
3. **讲一点，试一点：** 直觉与例子 → 图像 → 符号与公式 → 一个小练习。一次只提出一个主要学习问题，留出作答空间。
4. **边学边调整与保存：** 根据答案和体感改变解释方式、步幅与练习；完成小知识点或获得重要反馈后保存检查点。
5. **结束或暂停：** 收起新内容，写入记录，告诉你这次学了什么、哪些已能独立完成、哪里待补、下次从哪里接。

体感随时说即可，不要求打分。若适合询问，只用一个可选问题，例如“刚才是偏简单、刚好，还是偏吃力？”；你说结束时不会为了采集反馈把你留住。未提供的体感记作“未反馈”。

## 记录哪些内容

| 记录项 | 记录依据 |
| --- | --- |
| 本次内容和进度 | 实际讨论过的概念与完成的活动，不以预先生成的教材代替 |
| 你的体感与偏好 | 你明确说过的话，例如符号密、例子有帮助、今天疲劳；注明是本次感受还是稳定偏好 |
| 理解与运用 | 直觉解释、符号/形状、推导/手算、变式应用，分别记“未评估 / 需提示 / 可独立完成” |
| 证据与困难 | 你的关键回答摘要、用了什么提示、哪一步不清楚；必要时保留原话，不复制全部聊天 |
| 课程调整 | 原因、具体改变、补充内容是否必须、从哪里回到主线 |
| 下次接续点 | 精确到概念或未完成问题，而不只写“继续学习” |
| 复习安排 | 真正学过的概念、实际学习日期和下次提取问题；复习表现用于调整间隔 |

**体感和掌握分开看。** 觉得轻松但暂时不能独立做，就换个小例子再验证；觉得吃力但已经会做，就放慢或缩短练习，不抹掉已获得的能力证据。看过答案后复述，记为看过提示后的表现；隔一段时间能自己回忆，再记录新的独立证据。

## 怎么调整课程

- **概念卡住：** 查清是符号、前提还是推导缺一步，针对性补一个最小内容块。
- **稳定会做：** 减少重复，加入一个变式或进入下一个依赖概念。
- **记不牢：** 通过回忆和隔日变式复习，保留原有记录；一次失误不直接撤销过去的独立表现。
- **状态疲劳：** 降低本次负荷，保留当前未完成点。
- **出现兴趣：** 加入相关的小拓展，例如从点积看 Attention；注明是预览，并在拓展后回到当前任务。
- **需要新前置：** 自主加入必要补习，解释用途；大块的无关主题放入选修，不挤占当前主线。

默认只调整下一小步或接下来 1–2 次学习。反复出现的证据表明路线需要变化时，再修改较大范围的课程，并记录理由；不根据一句“难”重排整个学期。

## 保存与跨聊天继续

- [学习状态](LEARNING_STATE.md)：最新起点、当前会话、掌握证据索引、下次做什么。
- [逐次学习记录](sessions/README.md)：每次实际学习的过程、体感、表现与调整。
- [复习队列](REVIEW_QUEUE.md)：按实际学习日期生成的复习条目，优先处理薄弱内容。

关键检查点在对话回复过程中写入本地文件。“结束学习”会补上收尾；如果忘了说结束便关闭聊天，下次从最近**已经保存**的检查点继续，助手无法在关闭后补写尚未保存的内容。

在同一项目的新聊天中说“继续上次学习”即可读取这些记录；换到无法访问项目文件的聊天，需要提供记录。文件记录可随时查看或纠正，不以聊天记忆作为唯一依据。复习队列不会在后台主动发通知。
