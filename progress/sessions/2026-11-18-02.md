## Checkpoint 1: probability as a prediction for a class

- Teaching setup: for one image, the possible classes are `cat`, `dog`, and `bird`.
- An event is the outcome we are talking about, such as “the image is a dog.”
- A model can assign probabilities to the possible classes. These numbers are between 0 and 1 and sum to 1 across the classes.
- If the true class is `dog` and the model outputs `P(dog)=0.8`, the probability assigned to the correct class is `p=0.8`.
- This is a model output, not a guarantee that the image is a dog. It expresses the model's confidence.
- Next check: identify the correct-class probability from a small probability table, then introduce `-ln(p)` as the loss for one example.

## Checkpoint 2: reading the correct-class probability

- Exercise: the true class was `bird` in a table with `P(cat)=0.25`, `P(dog)=0.60`, and `P(bird)=0.15`.
- Learner answered `0.15` independently. Correct: the probability assigned to the correct class is `p=0.15`.
- This verifies the basic distinction between the true event and the model's probability for that event.
- Next: connect the correct-class probability to one-example negative log loss.

## Checkpoint 3: confidence and log loss

- Introduced one-example negative log loss: `ell=-ln(p)`, where `p` is the probability assigned to the true class.
- Explained the direction with reference values: `p=1` gives loss `0`; smaller `p` gives larger loss; probabilities close to `0` receive a very large penalty.
- Exercise: compare Model A with `P(dog)=0.8` and Model B with `P(dog)=0.2` when the true class is dog.
- Learner answered: “Model A, it has a higher probability.” Correct independently. This verifies the qualitative relationship between correct-class probability and log loss.
- Next: average one-example losses across a small dataset, if the learner continues this session.

## Checkpoint 4: mean loss across examples

- Introduced dataset-level mean negative log loss:
  `L=(1/n) sum_i [-ln(p_i)]`.
- Worked example: `p_1=0.5`, `p_2=1.0` gives losses approximately `0.69` and `0`, so the mean is `0.345`.
- Exercise: two examples both have `p=0.5`, so each loss is approximately `0.69`.
- Learner answered `0.69` independently. Correct. This verifies that the dataset loss is the average of the individual losses.
- The first B6 small goal is complete for probability reading, log-loss direction, and mean loss. A transfer question about confident errors is pending.

## Checkpoint 5: transfer to a confident low-probability example

- Transfer comparison: Dataset A has correct-class probabilities `[0.9, 0.9]`; Dataset B has `[1.0, 0.1]`.
- Learner answered: “B, because p2 in dataset B has a larger log loss.” Correct independently.
- This verifies that the learner can transfer the rule beyond the original two-model example and understand why one small `p_i` can dominate the mean.
- Next: connect the same one-example loss to a categorical probability vector and a one-hot target.

- Correct. The one-hot target marks the third class, and the loss uses `p_true=0.5`.
- This completes the B6 small goal: read class probabilities, compare negative log loss, average losses, and connect the scalar form to categorical cross-entropy.
